# Webová konzole — implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nahradit 501 stub plnou webovou konzolí: přihlášení dvěma kódy, správa lidí/skupin/aplikací/správců, audit — server-rendered Flask/Jinja2, CZ/EN z JSON katalogů, vše testované bez sítě.

**Architecture:** Nový subpackage `access_manager/konzole/` (`app.py` s `create_console_app(cfg)`, `templates/`, `preklady/cs.json|en.json`, `preklady.py` loader). Relace = flask session s klíčem generovaným při startu; CSRF token v relaci; per-request `FileStore` s `actor="admin:<jméno>"`. `FileStore` dostává veřejné `audit_event` (server přestává sahat na `_audit`). `main()` zapojí konzoli na listener 22001.

**Tech Stack:** Flask+Jinja2 (už v `[server]`), pyotp v testech. Žádná nová závislost.

**Spec:** `docs/superpowers/specs/2026-08-24-konzole-design.md`. Pozadí: spec realms v git historii (7b0868b), design canvas.

## Global Constraints

- Testy bez sítě: konzole přes `create_console_app(cfg).test_client()`; přihlášení v testech dvěma sousedními kódy přes pyotp (`totp.at(t)`, `totp.at(t+30)` na tajemství z disku). Po každém úkolu `./.venv/bin/python -m pytest` zelené + `./.venv/bin/ruff check .` čistý. Baseline 275.
- Každá mutace = POST s CSRF tokenem; nesouhlas → 400 a žádný zápis; GET nikdy nemutuje. Bez platné relace → redirect na `/login` (mimo `/login` a statické).
- Neúspěšné přihlášení = jedna hláška bez důvodu (podrobnost v auditu); throttled ukazuje `retry_after`.
- Tajemství/klíče/kódy nikdy do HTML mimo vyhrazená místa: QR jen na stránkách párování (`<pre>` z totp.txt), klíč aplikace jen JEDNOU na výsledkové stránce registrace.
- UI texty VÝHRADNĚ přes překladové klíče `t("...")` — žádný natvrdo zadrátovaný český text v šablonách; katalogy cs+en mají identické množiny klíčů (test to jistí). UI copy v katalozích JE s diakritikou (cs) — je to obsah, ne kód.
- Kód a komentáře česky bez diakritiky; testy anglicky; commity česky, malými písmeny, s trailerem `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>` po prázdném řádku.
- Vizuální tokeny (sdílený layout): sidebar #14352A, papír #F6F7F5, akcent #166B52, text #20241F, monospace na identifikátory; jeden `layout.html`, inline `<style>`.

```python
"""Preklady konzole. Kazdy text UI je klic do JSON katalogu.

Chybejici klic NIKDY neshodi stranku: spadne se na cestinu a pak na klic
samotny - preklep v sablone je videt, ne 500.
"""
from __future__ import annotations

import json
from importlib import resources


def nacti(lang: str) -> dict[str, str]:
    jazyk = lang if lang in ("cs", "en") else "cs"
    zdroj = resources.files("access_manager.konzole") / "preklady" / f"{jazyk}.json"
    return json.loads(zdroj.read_text(encoding="utf-8"))


def prelozit(katalog: dict[str, str], klic: str) -> str:
    if klic in katalog:
        return katalog[klic]
    zaloha = nacti("cs")
    return zaloha.get(klic, klic)
```
